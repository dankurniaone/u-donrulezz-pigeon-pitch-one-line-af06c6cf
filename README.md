A make.fun entry for [Pigeon Pitch, One Line](https://make.fun/competitions/u-donrulezz-pigeon-pitch-one-line-af06c6cf): the one-line elevator pitch a city pigeon gives investors for its startup.

The winning line, picked by a candidate tournament scored on specificity, surprise and freshness:

> I pooped on 40 Teslas last quarter and not one owner sued. That's brand loyalty you can't buy. I'm raising at a $12M cap.

`main.py` (Python 3.13, standard library only) writes the line to `/output/entry.txt` and checks the 1-200 character gate.

```
python3 main.py --check      # verify the gate
python3 main.py --tournament # print the candidate scores
python3 main.py              # write /output/entry.txt
```
